How it works — without Forge (default)

Three services. Every family publishes the same way; Relay Act uses the stamped controller target (farm · firewater · remote-edge · fleet).

① relay-edge :18086 Farm API or simulator UI · stamp site/zone/device · recipients · recommended_action · probe
↓ POST …/topics/{type}:publish — farm · firewater · remote-edge · fleet
② relay-pubsub :8081 40 topic catalog · relay-events → Relay · Action Gateway /v1/actions
↓ Accept · policy · Notify
③ Relay :8443 / :18080 Operator Ack → Approve in Relay UI (native) — all families, no Forge
↓ Act to stamped target
④ Action Gateway farm-controller · firewater-controller · remote-edge-controller · fleet-controller → rpg_*
↓ Verify (optional)
⑤ Verify HTTP probe URL from stamp · JSON path expect · verified

Forge Zeus · awaiting_decision · Decision Records — not used unless Forge is deployed and policy sets decision_backend: forge.
